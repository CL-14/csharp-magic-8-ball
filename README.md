# C# Magic 8-Ball Console App

A classic, interactive Magic 8-Ball simulation built in C#. Ask a yes-or-no question and receive one of twenty randomized traditional answers

## Features
* **Interactive Prompt:** Captures and greets the user by name.
* **Randomized Logic:** Uses C#'s `Random` class to select from the standard set of 20 classic Magic 8-Ball responses.
* **Replay Loop:** Features a `while` loop allowing users to ask multiple questions without restarting the application.

## Tech
* **Language:** C# (.NET Console Application)
